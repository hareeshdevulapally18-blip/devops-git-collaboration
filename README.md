
# DevOps Git Collaboration Project

## Project Objective
To learn Git version control and collaborate with team members using branching and pull requests.

## Technologies Used
- Git
- GitHub
- Visual Studio Code
- HTML

## Team Members
- Member 1: Project Lead
- Member 2: Developer
- Member 3: Reviewer

## Workflow
1. Create a Git repository.
2. Create separate branches for team members.
3. Make changes and commit the code.
4. Push branches to GitHub.
5. Create pull requests.
6. Review and merge changes into the main branch.
